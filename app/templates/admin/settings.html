How to configure SMTP or Resend

Set these environment variables in Railway (or your .env for local dev) and redeploy:

For SMTP (e.g. corporate mail relay, Gmail App Password, Mailgun SMTP):

MAIL_BACKEND=smtp
MAIL_FROM=vigil@your-domain.com
MAIL_BASE_URL=https://vigil-production-86a1.up.railway.app
MAIL_SMTP_HOST=smtp.your-provider.com
MAIL_SMTP_PORT=587
MAIL_SMTP_USER=your-username
MAIL_SMTP_PASSWORD=your-password
MAIL_SMTP_USE_TLS=true

For Resend (https://resend.com — sign up, verify your domain, generate API key):

MAIL_BACKEND=resend
MAIL_FROM=vigil@your-verified-domain.com
MAIL_BASE_URL=https://vigil-production-86a1.up.railway.app
MAIL_RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxx

Default backend is console — emails are logged but not actually sent. Useful for testing without a mail provider.
