! Don't pick cloud-synced folders

Avoid OneDrive, iCloud, Dropbox, or Google Drive folders. Those services may show "download" prompts when Vigil reads file metadata, even though Vigil never downloads anything. Pick a mapped network drive (e.g. Z:\Backup Logs\Archive) or a local-only folder.

1 · Pick the backup folder

Click Browse and choose the folder where the backup files live (typically your mapped drive — Z:\Backup Logs\Archive or similar).

2 · Describe the actual path required

Browsers don't expose the full Windows path — only the folder name. Type the real path here so this scan can be identified later (e.g. Z:\Backup Logs\Archive on MARS).

3 · Workstation (optional, remembered on this machine)

A short name for this workstation, e.g. MARS-WS-01. Helps identify which machine ran the scan.

4 · Run the scan

Vigil walks the folder, builds the manifest in your browser, and submits it for diff against the previous scan of this folder.
