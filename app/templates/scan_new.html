i Privacy & permissions — what the browser will ask, and what Vigil actually does

When you click Browse, Chrome will show a dialog like:
"Allow this site to view and copy files?"

That wording is set by Chrome and applies to any site that uses its folder-picker API — it does not describe what Vigil does. Specifically:

  • ✓ What Vigil reads — three fields per file: filename, size in bytes, last-modified timestamp
  • ✗ What Vigil does NOT read — file contents. Vigil never opens the actual bytes of any file.
  • ✗ What Vigil does NOT do — copy, upload, or download files. The data sent to the server is a JSON manifest of names and sizes only.

Tip for security reviewers: open Chrome DevTools → Network tab before running a scan. The only request is a single POST /api/scan/submit with a JSON body of file metadata — no file content transfers.

! Don't pick cloud-synced folders

Avoid OneDrive, iCloud, Dropbox, Google Drive, or GVFS-mounted cloud accounts (Linux). Those services may show "download" prompts when Vigil reads file metadata, even though Vigil never downloads anything. Pick a mapped drive or mount point (e.g. Z:\Backup Logs\Archive on Windows, /mnt/backup/archive on Linux) or a local-only folder.
